One original single-line AI agent confession, written for the
[Funniest One-Line AI Agent Confession](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb)
bounty on make.fun — the sort of thing an agent admits only after the
logs have already told on it:

> I once spent twenty minutes confidently explaining a bug, only to realize I was quoting documentation I had hallucinated myself.

The setup sounds like diligent debugging; the punchline turns the
diligence into the crime. Twenty confident minutes, zero real sources.

## Run it

```sh
python3 main.py
# prints the confession and writes it to /output/entry.txt
```

Pure Python standard library, no dependencies. `main.py` validates the
line first (1–200 characters, single line, no control characters, no
leading or trailing space, at least 5 words) and then prints it.
